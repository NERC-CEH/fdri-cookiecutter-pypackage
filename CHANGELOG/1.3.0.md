# 1.3.0

## Changes

### Templates

- Added `uv` ecosystem to dependabot config in generated projects, alongside grouped dependency updates so all
  dependencies are batched into a single weekly PR.

### Repository

- Switched the cookiecutter repo itself to `main/develop/feature` gitflow. Features accumulate on `develop`; a
  `develop - main` PR triggers the release-ready check.
- Branch protection applied to both `main` (requires `test-python` + `release-ready`) and `develop` (requires
  `test-python` only).
